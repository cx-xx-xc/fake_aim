# Aim Trainer 3D Implementation Plan

**Goal:** 在现有 DSH 插件中交付接近 Aimlabs 的三维训练、全屏应用布局与成绩页。

**Architecture:** 原生 WebGL 场景和可测试的训练状态模块，React 负责应用界面，复用现有 MQTT 房间。构建仍生成可离线运行的单脚本。

**Tech Stack:** JavaScript ESM、WebGL、Pointer Lock、React（由 DSH 提供）、Node test。

## 1. 三维场景

- [x] 先增加 `test/scene3d.test.mjs`：中央射线命中前方球体、最近球体优先、转动相机后命中右侧球体、背后目标不命中、俯仰有限、标准化目标映射一致。
- [x] 运行 `node --test test/scene3d.test.mjs` 确认缺失功能失败。
- [x] 增加 `src/scene3d.js`：数学函数和 WebGL 房间、球体、枪械、射击反馈；提供 `createSceneRenderer(canvas).render(state)` 与 `dispose()`。
- [x] 运行数学测试；浏览器验证 WebGL 画面与命中一致。

## 2. 训练与输入

- [x] 先增加 `test/range.test.mjs`，验证三靶点击替换、反应提前点击、跟枪时间比例、暂停不消耗单人时间、联机按墙钟结束、隐藏后恢复和结束只提交一次。
- [x] 增加 `src/range.js` 训练状态方法和 `src/range-ui.js` React 工厂；训练逻辑使用相同射线测试，避免画面与命中区域分离。
- [x] Pointer Lock 由真实点击请求，失败显示信息；Esc 释放后的暂停与点击继续路径已实现；监听、动画帧、音频、图形资源与锁定有清理。
- [x] 独立保存三维设置、成绩历史和幽灵，兼容读取旧成绩展示。

- [x] 用 `RangeGame` 替代五个二维游戏组件，保留房间准备、进度、排名、退出和中继行为。

- 真实浏览器确认 WebGL 场景、Pointer Lock、三秒倒计时、转向命中、完整结算与本地记录；反应完成 8 轮、跟枪完成真实 20 秒，自动输入未改写训练状态或时钟。
